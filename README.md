📊 Comprehensive Analysis of Mobile Sales Metrics: A Power BI Case Study


📋 Overview


This project is a Power BI case study focused on analyzing mobile sales metrics to uncover actionable insights and support data-driven decision-making. The interactive dashboard provides a comprehensive view of key metrics such as total sales, transaction trends, customer ratings, and payment methods.

🌟 Features


📈 Sales Metrics Analysis:



Visualized 10+ key metrics, including total sales, transaction trends, and customer behavior.


🗺️ Dynamic Dashboards:


City-wise performance tracking with interactive maps.


Monthly sales trends and customer behavior patterns displayed through dynamic charts.


💡 Strategic Insights:



Identified actionable trends to improve strategic planning and operational efficiency.


🛠️ Tools Used


Power BI: For designing interactive dashboards.


Power Query: For data cleaning and transformation.


📂 Key Insights


📅 Monthly Trends: Visualized seasonal sales patterns to identify peak months.


🌍 City-wise Performance: Analyzed regional differences in sales and customer behavior.


⭐ Customer Behavior: Assessed ratings and payment method preferences, guiding customer-focused strategies.


🚀 How to Use


Open the Power BI File:



Download and open the .pbix file in Power BI Desktop.


Explore Dashboards:


Use the interactive filters and slicers to analyze metrics by region, time period, or customer preferences.


Customize Insights:



Adjust visuals and data sources as needed for further analysis.


💡 Future Enhancements


Integrate real-time data sources for live tracking of sales metrics.


Expand the dashboard to include forecasting features using predictive analytics.


Add additional metrics like product returns and marketing campaign performance for deeper insights.
